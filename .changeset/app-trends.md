Each app's memory over time, with a projection. The Server section lists every app with its memory, CPU and a small chart, and says when an app that keeps growing will reach its limit (or fill the server, if it has none). An app heading there within 2 weeks gets advice and changes the server's status, so a slow leak shows up days ahead. `nook-admin headroom` prints the same list.
